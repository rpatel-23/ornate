# Data

`math500.jsonl`: MATH-500, 500 problems from the MATH benchmark (Hendrycks et al., 2021), picked by OpenAI for *Let's Verify Step by Step* ([prm800k](https://github.com/openai/prm800k)). Downloaded from [HuggingFaceH4/MATH-500](https://huggingface.co/datasets/HuggingFaceH4/MATH-500). Used by `eval_math500.py`.
